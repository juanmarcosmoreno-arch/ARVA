# Example data

## `synthetic/` — SYNTHETIC reads (not biological data)

| File | Content |
|------|---------|
| `SYNTHETIC_nanopore_reads.fastq.gz` | 400 long reads, log-normal lengths (N50 ≈ 5 kb), qualities around Q14 |
| `SYNTHETIC_illumina_R1_001.fastq.gz` / `_R2_001` | 2,000 read pairs of 150 bp, AT-rich composition, quality decaying towards the 3′ end |

These files are generated by `scripts/make_synthetic_reads.py` (deterministic seed).
Sequences are **uniformly random** and have no biological meaning; every header
contains the word `SYNTHETIC`. Use them to try the import → read statistics →
report flow, and in automated tests. Do not interpret their results biologically.

Regenerate with:

```bash
python3 scripts/make_synthetic_reads.py examples/synthetic
```

For real bacterial data, public runs from the ENA/SRA (for example Nanopore or
Illumina runs of *Staphylococcus aureus* isolates) can be downloaded and
imported directly.
